# Brand icons

These icons identify the agent harnesses, model vendors, and tools that appear in a trace. Each mark belongs to its owner. They are used here only to name the product a span came from, and no endorsement is implied.

- AI harness and model icons come from [LobeHub Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.98.0), MIT license.
- Tool and service icons come from [Simple Icons](https://github.com/simple-icons/simple-icons) 16.35.0, CC0 1.0. Their brand colors also come from Simple Icons: GitHub `#181717`, Notion `#000000`, Figma `#F24E1E`, Stripe `#635BFF`, Linear `#5E6AD2`, Vercel `#000000`, Google Drive `#4285F4`, PostgreSQL `#4169E1`, Docker `#2496ED`, Git `#F03C2E`.

Files ending in `-color` are full color. The others are single-color marks meant to be tinted.
